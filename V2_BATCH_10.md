# PDF Master Tools V2 — Professional Batch 10

## Major upgrades
- PDF Page Editor can insert multiple gallery images as new pages.
- Inserted image pages can be reordered, rotated, duplicated by normal editor flow, and deleted.
- PDF page editor preserves original PDF pages while rebuilding a new output PDF.
- OCR now reports PDF page progress.
- OCR has a cancellation token and a Cancel action in the extraction screen.
- Urdu, Arabic, English and mixed OCR paths remain supported.

## Verification note
This batch was source-assembled but not compiled on Android Studio in this environment. Final Gradle/build/device verification is still required.
